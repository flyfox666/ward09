# Ward09 V1.9 · 最后生还者：封锁撤离

Windows 试玩版。独立程序的正常输入自动通关及相关运行检查见同目录 `VALIDATION.md`；人类首玩时长与主观听感仍未确认。

## 启动与选择模式

将压缩包**完整解压**到可写的本地文件夹，保留 `Ward09.exe`、`Engine`、`Ward09` 等全部文件，双击同目录的 `StartGame.cmd`。也可直接运行 `Ward09.exe`。游玩不需要安装虚幻引擎、Epic Games Launcher，也不需要联网。

当前 Windows x64 包默认使用 **DirectX 12 / Shader Model 6** 渲染，需要支持这一默认路径的显卡及驱动。最低 CPU、内存、显存和帧率尚未建立实测标准；低配与干净 Windows 的兼容性需另外测试。工程配置也列有 DirectX 11 着色器格式，但本包没有验证 DX11 降级路径。

开始菜单提供：

- **故事战役**：原病区序章及后续五区战役。
- **最后生还者 · 标准**：独立特别行动，总撤离窗口为 12 分钟。
- **最后生还者 · 困难**：同一撤离路线，备用弹药更少、污染更快，总窗口为 11 分钟。

在开始界面或 Esc 菜单切换中文 / English，菜单、目标、字幕及对白同步切换，不会重新开始行动；语言偏好在本地保存。

## 故事与目标

转运队失联，行动队员灰隼携带封存样本穿过故障设施，林岑通过对讲机协助。这是与原战役平行的特别行动，不改变战役进度。

1. 根据当前目标和小地图标记，**依次验证三个转运终端**。靠近对应终端，按 **E**。
2. 到北侧气闸控制台按 **E**，发送撤离信号。
3. 坚持生存，等待气闸完成 **45 秒净化**。北侧气闸区不受分区污染，但怪物仍可能追来。
4. 气闸就绪后，**实际走进撤离标记**。只等倒计时结束不会自动通关。

无需清空全部怪物。可以击杀、利用普通怪物硬直的短暂机会绕过，也可以选择两侧维修路线避战。装甲与重型威胁有不同抗性，不是每次命中都能阻止它们。

## 装备、补给与污染

起始装备为刀、手枪、散弹枪、冲锋枪和狙击枪，另有**两枚手雷、两个医疗包**。特别行动中不能使用重机枪。每个医疗包最多恢复 40 点生命，上限 100。

| 武器 | 已装弹药 | 标准备用 | 困难备用 |
|---|---:|---:|---:|
| 手枪 | 15 | 45 | 30 |
| 散弹枪 | 7 | 14 | 7 |
| 冲锋枪 | 32 | 96 | 64 |
| 狙击枪 | 5 | 15 | 10 |

地图有三个固定补给点，分别提供弹药、医疗补给和手雷。靠近可触及的补给按 E，或走到其近旁即可拾取。补给只能取一次，**特别行动击杀不掉落补给**。

后方分区逐步污染。倒计时、警灯和小地图使用同一行动时钟，每个分区污染前有 **30 秒预警**。红色区域会持续损伤生命，应向前转移。污染不会用永久关门的方式封死唯一前进路线。

## 操作与设置

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 环视 |
| 左键 / 右键 | 攻击 / 枪械瞄准 |
| 1 / 2 / 3 / 4 / 6 | 刀 / 手枪 / 散弹枪 / 冲锋枪 / 狙击枪 |
| 鼠标滚轮 | 切换当前模式可用武器 |
| R / G / Q | 装填 / 手雷 / 医疗包 |
| E | 操作当前终端或拾取可触及补给 |
| 空格 | 跳跃 |
| M / H | 小地图 / 怪物血条开关 |
| J | 查看故事战役行动记录 |
| Esc | 暂停、设置、说明、返回模式选择或退出 |
| F9 | 立即重开当前模式；特别行动保留难度 |

故事战役另有 **5 号重机枪**。菜单可用鼠标点击；上下方向键或 Tab 选择，左右方向键调节，Enter 确认。

Esc 设置可调鼠标灵敏度、Y 轴反转、分辨率，以及全屏、无边框或窗口模式。应用显示设置后，15 秒内确认保留，否则自动恢复之前设置。音乐、音效、环境声有独立音量；**剧情语音**开关同时控制男主角和女协助员，关闭后保留字幕及其他声音。对白是原创短台词的神经合成语音，分别作近场和对讲机处理，并非真人录音。

独立程序已实测暂停/恢复的行动时钟、装填、移动、语音及语言设置，并在实际气闸净化期间观察到四个活跃移动敌人冻结。两次暂停的录制主混音在测量区间为静音，恢复后重新有声音信号。具体范围见 `VALIDATION.md`，这些检查不代替人工听感。

## 结算与记录

撤离成功、死亡或总窗口超时均会结束行动。结算显示原因、时间、击杀、射击、治疗次数和本难度最佳成功时间。更快的成功成绩更新对应难度记录，失败不会覆盖；标准和困难记录分开保存。设置会保存，进行中的战役或特别行动不支持退出后续玩。

F9 立即重开；Esc 中可使用带确认的重开、返回模式选择或退出。重开或返回菜单会结束当前行动。

首次游玩时长、人工听感和硬件兼容性的未确认项见 `KNOWN_LIMITS.md`。V1.9 使用独立目录，保留 V1.7 成品及现有公开下载。

## V1.9 新增操作

按住 Shift 快跑，松开恢复步行；瞄准、开枪和装填时停止快跑。6 切换栓动狙击枪，右键使用狙击镜。战役仍有 5 号重机枪；封锁撤离可用 1–4 和 6。

封锁撤离采用新的转弯路线：病区 → 机电区 → 装卸场 → 中转大厅 → 北气闸。起始病区有电动代步板：E 上下板、W/S 前后、A/D 转向、空格刹车。电量为 45 秒有效移动时间，暂停不消耗；射击或操作终端前必须先下板。代步板为平地原型，不支持楼梯或跳跃。
